- БД (отдельный стенд): `SELECT count(*) FROM sales_tasks WHERE goal LIKE 'Проверка V2-R01%'` → **1**, row_version=1, status=open

Код: `tools/crm-agent-client.ts` — новая функция `extractIdempotencyKey` (без splice; значение читается до пропуска), заголовок `Idempotency-Key` ставится для всех команд. Нарушений AGENT-02-AC02/03, AGENT-04-AC02, V2-E2E-10 в этом сценарии больше нет.

   первый вызов создал задачу и вернул её клиенту (маркер `result_unknown` записан повторной попыткой); повтор с тем же ключом вернул сохранённый `result_unknown` без второй мутации; **persisted=1**, состояние записи `completed`. Дубля нет — дефект аудита устранён.
